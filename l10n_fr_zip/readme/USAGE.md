1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the French localities of that postal code are listed with their département.

   ![Cities list filtered on the postal code 01090: the localities Francheleins, Genouilleux, Guéreins, all of the state Ain (FR)](static/description/en/01_lista_localitati_cap.png)

2. Open a French contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in France: the postal code 01440 fills in the city Viriat and the state Ain (FR)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in France: the postal code 01090 fills in the state Ain (FR); the city field lists the localities of 01090](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → France: set city from ZIP*.

   ![Contacts list with French contacts selected and the Actions menu open on France: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Customer Francheleins after the action: ZIP 01090, city Francheleins (01090) and state Ain (FR)](static/description/en/05_contact_dupa_actiune.png)
